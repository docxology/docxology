## Abstract

antropy v0.3.1 provides typed, configurable entropy and complexity methods for native multidimensional data, including high-dimensional sample entropy (HDSE), related local-template estimators, probability and dependence measures, ordinal measures, FFT/SVD entropy, resource planning and whole-observation inference. This software archive includes reproducible synthetic experiments, prospective power and null-calibration studies, tests, documentation, configuration plans, provenance and the methods manuscript rendered through the pinned docxology/template pipeline. Synthetic demonstrations do not establish biological sample sizes or reproduce the original HDSE paper’s empirical results. Version 0.3.1 adds an authenticated root-level copy of the rendered manuscript; the underlying scientific study snapshots retain their original producer metadata. Repository: https://github.com/docxology/antropy.

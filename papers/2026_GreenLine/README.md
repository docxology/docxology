## Abstract

A capacity-under-development instrument: the green line of the docxology line-set. It records what is deliberately still being learned — apprenticeships, skills not yet mastered — with marker/counter-signal staging, and reads declared growth records against a versioned registry. Observations phrased as certification or credential language are staged aside with a note, never scored. It measures what is still growing — never competence, mastery, or virtue.

# Art Collections

Curated crawlable collection hubs generated by
[`code/orchestrators/build_artwork_pages.py`](../code/orchestrators/build_artwork_pages.py)
as `art-collections/<slug>.html`. This table is the single source of truth for
theme pages; edit it, then rebuild (the generator is in the local generation
plan as the `artwork-pages` step).

A work joins a collection when any of its Flickr tags — normalized lowercase,
spaces removed — is listed in the **Tags** column, or when any **Title
keywords** phrase occurs in the work title. Keep Tags columns specific: the
near-universal tags (`draw`, `ink`, `paper`, `art`, `sketch`, `cartoon`,
`science`, `philosophy`, `geometry`, `topology`, `mathematics`, `freedraw`,
`freehand`, `doodle`) are intentionally excluded so hubs stay topical. Intro
copy is approved by DAF; cells are pipe-delimited and must not contain pipes.

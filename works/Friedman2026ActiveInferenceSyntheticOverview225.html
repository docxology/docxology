Overview

Public distribution 0.6.1 of Active Inference -- A Synthetic Overview. This successor archives the revised 28-page paper, complete twenty-minute Daniel lecture, linked slides, English captions, current repository source archive, frozen lecture replay inputs and verification metadata. Scientific package/manuscript version remains 0.5.0; the paper and lecture preserve the verified edition_v15 teaching-release bytes. Documentation is updated throughout the public repository. No numerical model, scientific result or Lean proposition is changed. The source ZIP is bound to the exact commit in RELEASE_IDENTITY.json; the replay ZIP retains the original media inputs and runtime. GitHub release: https://github.com/docxology/ActiveInferenceSynthetic/releases/tag/synthetic-public-v0.6.1 . Earlier edition: https://zenodo.org/records/23321281 .

The Silver Line: A Memory-and-Succession Instrument

Daniel Ari Friedman

Zenodo

Download PDF Publication source Paper folder on GitHub Read extracted text

Overview

A memory-and-succession instrument in the docxology line set. It reads a declared succession picture — what is preserved, what is entrusted to whom, what is allowed to lapse — and returns a verdict about declared provision and review gaps, pinned to a registry digest. A KEPT verdict describes declared custody at a review date; it is never permission and never a promise that anything survives. Findings and contributions

  • On the worked lab-archive example, the reading returns NEEDS_PROVISION, while the empty-registry control fails closed.
  • The formalism states that an empty scan set yields OUTSIDE_SCOPE with an intake note, and an unscorable registry yields NEEDS_REWORK with no findings.
  • A gap on a lapse-accepted keepsake is treated as a declared release (NEEDS_PROVISION), not a defect.
  • The paper limits verdicts to declaration coverage: it does not verify labels are real, judge quality, or guarantee survival.

Methods

  • Keepsake registry with retention, restraint and lapse families — Declares kept items in a registry that carries restraint and lapse families alongside retention, so lapse is part of the declaration.
  • Staged intake that sets aside malformed content with a note — Normalizes each declared succession item at intake; malformed content is noted and set aside rather than crashing or being repaired.
  • Tag-intersection matching and present/missing evidence-label split — Matches keepsakes to items by intersecting tags, then splits each keepsake's required evidence labels into present and missing.
  • Verdict pinned to ISO review date and SHA-256 registry digest — Each succession reading's verdict is tied to the review date and a SHA-256 digest of the keepsake registry that produced it.
  • Worked example envelope: small lab-archive succession — Runs the reading on a worked JSON example with one declared record, a named custodian and a partial evidence set, plus an empty-registry control.

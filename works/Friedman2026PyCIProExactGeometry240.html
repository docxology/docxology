py-CIPro: Exact geometry of complete-intersection Calabi–Yau threefolds

Daniel Friedman

Zenodo

Read PDF on Zenodo (version 0.9.3) Publication source Paper folder on GitHub

Overview

py-CIPro provides Python bindings and exact native calculations for complete intersections in products of projective spaces. This release includes an interactive audit of the Riemann–Roch index fixed divisor on ambient CICY3 divisor lattices. The archive contains the software wheel, manuscript, graphical abstract, vector figures, and record-level analysis data.

Source code: https://github.com/docxology/py-CIPro (release v0.9.3 (https://github.com/docxology/py-CIPro/releases/tag/v0.9.3)).

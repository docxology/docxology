# AGENTS.md — `resume/`

Public CV/resume sources and tracked generated exports. `source.json` owns
curated resume content; bibliography, software, claim, and verified Scholar
sources supply dependent data. Follow the root repository privacy rules.

- Edit authoritative sources, then run `code/orchestrators/build_resume.py
  --all` through `regenerate_all.py`; do not hand-edit generated HTML, PDF,
  plaintext, or JSON exports.
- Rebuild dependent exports after approved bibliography, software, or claim
  changes. Keep private records, local paths, and unsupported claims out.
- Scholar metric updates require the direct authenticated observation and
  snapshot-bound receipt required by the root instructions.
- Review and commit authorized public source/export changes on a work branch;
  use the repository validation and CV privacy checks before publication.

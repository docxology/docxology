What this site is

The public research and software index of Daniel Ari Friedman: hand-maintained curated sources backed by a generated data layer, all in one repository.

This site is the front end of docxology. Curated files (the bibliography, the software catalog, this page) are the sources of truth; everything generated — citation exports, per-work pages, search and agent indexes — is rebuilt from them. The full artifact map, including which files are generated and how to rebuild each one, is in GENERATED.md. The main layers:

  • Publications — a unified bibliography of 215 works rendered at publications.html, with a page per work under works/.
  • Software — 154 curated software projects at software.html, backed by a full GitHub repository inventory.
  • Paper folders — 198 folders under papers/, 190 with full-text extraction and 8,944 extracted images (recorded in data/current-counts.json).
  • Art — 942 catalogued pen-and-ink drawings at art.html, exported as artworks-index.json.
  • Video — 1,127 videos across the personal and Active Inference Institute channels at videos.html, exported as videos.json.
  • Evidence — a claim-level ledger at evidence.html and an executable reproducibility ledger at reproducibility.html.

If you are an agent

Machine-readable entry points, in roughly the order the repository itself recommends them.

  • llms.txt — the canonical machine-readable map: every page and dataset, the crawl policy, and the site's source-of-truth rules.
  • data/agent-index.json — the stable agent route manifest: routes, dataset schemas (schema registry 1.5), counts, and freshness metadata.
  • discovery.html — canonical public identifiers, public API endpoints, and repeatable query recipes for cross-checking claims.
  • data/works.json — the machine-readable registry of every work (num, citation key, URL, DOI, paper folder).
  • search-index.json — the full site search index; search.html is the human-facing version.
  • cite-verify.html — citation metadata and the verification rules: treat curated files as sources of truth and public API counts as freshness checks, not replacements.

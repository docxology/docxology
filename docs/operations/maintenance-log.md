# Historical maintenance log

This is the on-demand history for repository maintenance. The long dated table
was removed from always-loaded `AGENTS.md` so agents first see active operating
rules and source-of-truth boundaries.

Completed public-index, website, bibliography, discovery, accessibility, and
release work is recorded in [`CHANGELOG.md`](../../CHANGELOG.md), which is the
canonical human-readable history and source for the generated [`updates.html`](../../updates.html).
The dated reports under [`reports/`](../../reports/) retain the corresponding
machine-readable evidence and QA snapshots.

When investigating an earlier change:

1. Search [`CHANGELOG.md`](../../CHANGELOG.md) by date or subsystem.
2. Follow the linked source files and orchestrators.
3. Check the matching dated report and generated manifest entry.

Do not add completed work to [`TODO.md`](../../TODO.md); use the changelog and
dated evidence instead.

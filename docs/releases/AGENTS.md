# AGENTS.md — `docs/releases/`

Archived point-in-time release snapshots, one dated Markdown file each
(`2026-05-discovery-layer.md`), kept as a historical record.

- Do not rewrite a snapshot to match today's state: it records what was true when it was
  written. A correction to history belongs in a new dated note or in the maintenance
  log, not in the old file.
- New snapshots are dated and self-contained; nothing generates them and no test reads
  them.

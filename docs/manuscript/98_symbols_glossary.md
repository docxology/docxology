# Symbols and Glossary {#sec:symbols_glossary}

| Term | Meaning in this repository |
| --- | --- |
| Authored authority | Reviewed input such as the bibliography table or resume source, rather than its generated projection |
| Projection | Derived HTML, data, citation export, report, or bounded hosting artifact |
| Work identity | A reserved citation key and permanent work URL recorded in the identity registry |
| Shared namespace | The checkout-local package that keeps canonical and compatibility imports attached to one module object |
| Reading-list preview | A title and ordered citation keys that require explicit saving before becoming a saved browser list |
| CSL | Citation Style Language, used here for structured citation-manager records |
| RIS | A tagged citation-manager exchange format |
| JSON | JavaScript Object Notation, used for structured data and list backups |
| CSV | Comma-separated values, used for inspectable mathematical traces |
| Generation step | A declared writer with ordered inputs and its independent no-write check |
| Fingerprint cache | Ignored local optimization state used to avoid redundant writes; it is not validation evidence |
| Payload commit | Landed source and generated consumer content to which release controls can bind |
| Control binder | Generated release/provenance metadata refreshed against the landed payload |
| Technical deployment acceptance | Targeted checks of published routes, source/run binding, and specified objects |
| Human visual review | Explicit inspection and approval of identified captured screenshots |
| Full release attestation | The stronger fresh, candidate-bound requirements defined by release-integrity policy |

Definitions follow the [development](../operations/development.md), [regeneration](../operations/regeneration.md), and [release](../operations/release-integrity.md) runbooks.

# References {#sec:references}

Bibliographic entries live in [references.bib](references.bib). The repository entry identifies the system described in this draft, with author, title, and repository URL grounded in [CITATION.cff](../../CITATION.cff). It does not add a DOI or assert a new manuscript release.

Implementation evidence is linked directly throughout the sections and in @sec:source_surface. The declared renderer parses bibliography entries with Pandoc. The native PDF uses template-integrated crossref and BibTeX/natbib; other formats use crossref and citeproc. Structural validation, real-parser checks, rendered reference inspection, and editorial review remain separate evidence.

# References {#sec:references}

Bibliographic entries live in [references.bib](references.bib). The repository entry identifies the system described in this draft, with author, title, and repository URL grounded in [CITATION.cff](../../CITATION.cff). It does not add a DOI or assert a new manuscript release.

Implementation evidence is linked directly throughout the sections and in @sec:source_surface. A future renderer must document how it consumes the bibliography. Local validation checks citation-key resolution, while complete bibliography grammar and rendered references require separate verification.

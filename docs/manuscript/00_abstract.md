# Abstract {#sec:abstract}

docxology maintains a public research, software, and citation index through reviewed source tables, publication documentation, structured exports, and a static website [@docxologyIndex]. This methods draft explains how the repository carries reviewed identity and source decisions into generated discovery surfaces and revision-bound verification.

The method separates observation, curation, generation, hosting, and acceptance. Stable work reservations preserve citation and route identities; bounded source readers reject incomplete intake; explicit document evidence records edition and byline decisions. Shared parsers and an ordered generation plan produce the website and citation exports. A bounded hosting projection preserves existing local originals while permitting reviewed, versioned external PDF editions. Progressive catalogs and browser-local research tools support discovery without becoming new source authorities.

The draft provides source maps, reproducibility commands, an evidence taxonomy, failure conditions, and an evaluation protocol. It distinguishes byte identity, extraction accuracy, software behavior, remote availability, empirical validity, and human review. It reports an implemented design and documented maintenance cases, without a comparative benchmark, new scientific results, or a claim that search engines index every work. Rendering and structural acceptance remain separate from editorial approval and publication readiness.

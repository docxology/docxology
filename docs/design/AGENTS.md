# AGENTS.md — `docs/design/`

The site's design documentation: `design-system.md` (tokens and components),
`animations.md`, and per-component notes under `components/`. It is the written half of
the design system whose executable half is `style.css`.

- Keep the pair in step. The root guide assigns this synchronisation to the site work;
  a token documented here and not present in `style.css` is documentation of nothing.
- Nothing validates these documents and no test reads them: they are prose that the
  CSS, not a checker, has to agree with.
- Listing first: this guide is not an index of the components.

Repository rules: [root guide](../AGENTS.md).
